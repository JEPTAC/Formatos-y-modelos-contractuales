Publicar en GitHub Pages

  1. Cree un repositorio nuevo.
  2. Suba todo el contenido de esta carpeta a la raíz.
  3. Abra Settings → Pages.
  4. Seleccione Deploy from a branch.
  5. Elija la rama main y la carpeta / (root).
  6. Guarde y espere la URL pública.

No cambie los nombres de las carpetas assets y downloads, porque los enlaces son relativos.
