# GitHub Pages — Formatos y modelos contractuales ITA 3.5

Repositorio estático preparado para la **Alcaldía Municipal de San Pedro, Valle del Cauca**.

## Publicación rápida

1. Cree un repositorio nuevo en GitHub.
2. Cargue **todo el contenido de esta carpeta**, conservando la estructura.
3. Abra **Settings → Pages**.
4. En *Build and deployment*, seleccione **Deploy from a branch**.
5. Seleccione la rama `main` y la carpeta `/ (root)`.
6. Guarde y espere a que GitHub muestre la dirección pública.

El archivo principal es `index.html`.

## Verificación incluida

- Previsualización de la primera página de cada Word.
- Metadatos de control: código, versión, TRD y estado.
- Verificador local SHA-256 mediante selección o arrastre del archivo.
- Comprobación masiva de archivos publicados.
- `MANIFIESTO_SHA256.txt`.
- `assets/data/manifest.json`.
- `assets/data/catalogo.csv`.
- Página imprimible `evidencia.html`.
- Huella global del conjunto principal:

`208135664735a530a8862e902c7bef92f7b289e7c24be39aabe6c17cadf7eb80`

## Actualizar archivos

1. Reemplace el archivo en `downloads/documentos/`.
2. Recalcule su SHA-256.
3. Actualice `assets/data/manifest.json`, `MANIFIESTO_SHA256.txt` y `evidencia.html`.
4. Actualice fecha, versión y estado.
5. Publique el cambio mediante commit.

## Advertencia institucional

Los documentos son modelos vacíos, editables y transitorios, en proceso de revisión y aprobación. Cuando resulte obligatorio un Documento Tipo de Colombia Compra Eficiente, prevalece la versión oficial vigente.
